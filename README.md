Objetivo general:Diseñar, construir y controlar un aeropéndulo de dos hélices, regulando su ángulo mediante un controlador PID implementado en un microcontrolador STM32, de modo que siga una referencia y rechace perturbaciones.
Descripción general del proyecto:
El presente proyecto abarca el diseño, construcción e implementación del control de posición angular de un aeropéndulo de dos hélices limitado a un grado de libertad. El sistema utiliza un microcontrolador STM32 como unidad central de procesamiento para realizar la lectura de la posición angular mediante un sensor, ejecutar en tiempo real un algoritmo de control PID y ajustar la velocidad de rotación de los motores a través de señales PWM. 
El propósito principal es lograr la estabilización y el seguimiento de referencias angulares frente a perturbaciones externas, además de contrastar y validar la respuesta física de la planta contra un modelo dinámico previamente simulado.
